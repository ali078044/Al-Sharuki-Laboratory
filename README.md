# مختبر الفيزياء التفاعلي

تم تصميمه للأستاذ **علي محمد الشاروكي**.

مختبر افتراضي تفاعلي لكتابي الفيزياء العراقيين:
- **السادس العلمي** — 9 فصول (المتسعات، الحث، التيار المتناوب، الموجات، البصريات، الحديثة، الإلكترونيات، الذرية، النووية).
- **الأول المتوسط** — 5 فصول (خواص المادة، القوة، الضغط، الحرارة، أثر الحرارة).

## التشغيل
افتح الملف `index.html` بأي متصفح (يعمل دون إنترنت ودون تثبيت).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `physics-lab`).
2. ارفع محتويات هذا المجلد (أو استخدم GitHub Desktop: Add local repository ← اختر هذا المجلد ← Publish).
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)`.
4. سيصبح المختبر متاحاً على الرابط: `https://<اسم-المستخدم>.github.io/physics-lab/`

## بنية المشروع
- `index.html` — البرنامج الجاهز (ملف واحد).
- `src/` — الملفات المصدرية: `shell.html` و`styles.css` وملفات JavaScript لكل فصل.
- لإعادة بناء `index.html` بعد أي تعديل: `python src/build.py`
